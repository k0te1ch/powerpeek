## Зачем это нужно

Windows знает заряд геймпада. Просто не показывает — пока не откроешь приложение Xbox Accessories и
не оставишь его открытым.

Эта программа держит уровень заряда в области уведомлений и предупреждает **до** того, как геймпад
выключится, а не после. Один exe на 4 МБ: без установщика, без рантаймов, без службы, без сети.

## Что умеет

|   | |
|---|---|
| **Живой значок в трее** | Рисуется в рантайме, а не выбирается из готовых картинок: батарея, кольцо или проценты — в твоей теме и с твоим акцентным цветом, в том размере, который просит система. Если геймпадов несколько, показывает наименьший заряд и их количество. |
| **Свои звуки** | Пять событий — подключён, отключён, низкий заряд, критический, заряжен полностью. У каждого свой файл, своя громкость и кнопка «Проверить». WAV, MP3, FLAC, M4A. Пять встроенных звуков лежат прямо в exe. |
| **Два вида уведомлений** | Собственная карточка в стиле Fluent, которая не отбирает фокус у игры, и настоящие уведомления Windows в Центре уведомлений. Для каждого события — отдельно. |
| **История заряда** | График разряда каждого геймпада, скорость разряда и оценка оставшегося времени. |
| **Окно, которое выглядит своим** | Своя отрисовка в стиле Fluent, светлая и тёмная тема вслед за системой, поддержка DPI на каждом мониторе и анимация, которая ничего не стоит, когда ничего не движется. |
| **Настраиваемый цвет значка** | По умолчанию автоматический контраст с панелью задач — это важно, потому что панель, подкрашенная твоим акцентом, съедает значок того же цвета, — либо акцент системы, либо цвет на выбор. Янтарный и красный при низком и критическом заряде остаются в любом случае. |
| **Русский и английский** | По языку системы или по твоему выбору. |
| **Ничего не уходит наружу** | Ни телеметрии, ни аккаунтов, ни единой сетевой строчки кода. |

## Установка

Скачай `PowerPeek.exe` из [последнего релиза](https://github.com/k0te1ch/powerpeek/releases/latest)
и запусти. Это вся установка — программа состоит из одного самодостаточного файла и работает
оттуда, куда ты её положишь.

К каждому релизу собирается и установщик — ради записи в меню «Пуск» и корректного удаления;
портативная и установленная копии это одна и та же программа с общими настройками.

Чтобы запускалась вместе с Windows, включи **«Запускать вместе с Windows»** в параметрах.

Чтобы удалить: выйди через меню в трее, удали exe, а если хочешь стереть и настройки — удали папку
`%LOCALAPPDATA%\PowerPeek`.

## Требования

- Windows 10 версии 1809 или новее, 64 бита. Windows 11 поддерживается полностью и автоматически
  получает скруглённые углы окна.
- Геймпад Xbox: Xbox One, Xbox Series, Elite, Elite Series 2 или Adaptive — по USB, через адаптер
  Xbox Wireless или по Bluetooth.

Сторонние геймпады тоже можно показывать — для этого есть настройка, — но их показания заряда часто
неверны, поэтому по умолчанию они скрыты.

## Сборка из исходников

Нужна Visual Studio 2022 с рабочей нагрузкой **«Разработка классических приложений на C++»**. Она
приносит с собой Windows SDK, CMake и Ninja — больше ставить нечего: у проекта нет ни одной внешней
зависимости.

```bash
git clone https://github.com/k0te1ch/powerpeek.git
cd powerpeek
tools\build.bat release
```

Результат — `build\release\PowerPeek.exe`.

| Команда | Что делает |
|---|---|
| `tools\build.bat release` | Оптимизированная сборка |
| `tools\build.bat debug` | Отладочная сборка |
| `tools\syntax-check.bat src\ui\Widgets.cpp` | Компилирует один файл — быстрый цикл правок |
| `python tools\generate_assets.py` | Пересоздаёт иконку и встроенные звуки |

## Где лежат настройки

```
%LOCALAPPDATA%\PowerPeek\
    settings.json      настройки
    history.jsonl      история заряда
    PowerPeek.log
```

Удалить папку — значит вернуть всё к значениям по умолчанию.

## Частые вопросы

<details>
<summary><b>Почему проценты прыгают ступенями, а не меняются плавно?</b></summary>

Потому что геймпад больше и не сообщает. Протокол Xbox передаёт два бита уровня заряда, так что
«точная» цифра, которую отдаёт Windows, — это реконструкция примерно из четырёх ступеней.

Программа показывает проценты, потому что так понятнее всего, но честно помечает их приблизительными,
рисует историю по реальным переходам, а не выдуманной гладкой кривой, и не изображает точность,
которой нет. Всё, что показывает тебе «73,4 %», просто сочиняет.
</details>

<details>
<summary><b>Геймпад подключён кабелем и не показывает заряд. Это баг?</b></summary>

Нет. У проводного геймпада — и у беспроводного, работающего от кабеля без аккумулятора, — заряда
действительно нет. Программа пишет «по кабелю», а не «0 %», потому что принимать «нет батареи» за
«батарея пуста» — ровно та ошибка, из-за которой другие подобные программы поднимают тревогу на
совершенно здоровом геймпаде.

Если стоит аккумулятор Play & Charge, будет и уровень, и состояние зарядки.
</details>

<details>
<summary><b>Нужны ли приложение Xbox, Game Bar или драйверы?</b></summary>

Нет. Используется поддержка геймпадов, уже встроенная в Windows.
</details>

<details>
<summary><b>Уведомления Windows не появляются, а свои — да.</b></summary>

Windows показывает уведомления только для тех классических приложений, которые может опознать, а для
этого нужна запись в меню «Пуск». Программа создаёт её при первом запуске; если система или политики
это запрещают, уведомления Windows недоступны — и программа честно пишет об этом в параметрах. Свои
карточки при этом работают всегда, и у них есть преимущество: они не отбирают фокус у игры.
</details>

<details>
<summary><b>Можно поставить свои звуки?</b></summary>

Да, ради этого всё и затевалось. У каждого из пяти событий свой файл: WAV, MP3, FLAC, M4A — или что
угодно, для чего в системе есть кодек. У каждого своя громкость и кнопка «Проверить», а «Сбросить»
возвращает встроенный звук.
</details>

<details>
<summary><b>Почему маленькая утилита весит 4 МБ?</b></summary>

Она статически линкует библиотеку C, чтобы запускаться на любой машине без установки чего бы то ни
было, и пять встроенных звуков лежат прямо внутри exe. И то, и другое сделано намеренно: иначе
понадобились бы установщик и распространяемый пакет — ради программы, которая должна быть одним
файлом, который можно положить куда угодно.
</details>

<details>
<summary><b>Она куда-нибудь стучится?</b></summary>

Нет. В проекте вообще нет сетевого кода: ни телеметрии, ни проверки обновлений, ни аккаунтов. История
заряда — это файл на твоём диске, и читает его только сама программа.
</details>

<details>
<summary><b>А геймпады PlayStation и прочие?</b></summary>

Они появятся, если включить «Показывать не-Xbox геймпады», и некоторые действительно отдают вменяемый
уровень. Многие отдают чепуху — поэтому настройка выключена по умолчанию. Программа сделана и
проверена для геймпадов Xbox.
</details>

## Как поучаствовать

Issues и pull request'ы приветствуются.

- **Сначала собери.** `tools\build.bat release` должна оставаться без предупреждений.
- **Conventional Commits.** `feat:`, `fix:`, `docs:`, `refactor:`, `perf:`, `test:`, `build:`, `ci:`,
  `chore:`. Заголовок PR становится коммитом в `main` и определяет версию, поэтому он тоже обязан быть
  валидным Conventional Commit.
- **Никаких новых зависимостей.** Весь список зависимостей — это Windows SDK, и то, что он таким
  остаётся, здесь считается функцией, а не случайностью.
- **Весь видимый пользователю текст живёт в `src/core/Strings.h`**, сразу на двух языках: пропущенный
  перевод — это ошибка компиляции, а не сюрприз в рантайме.
- **Держись стиля вокруг.** Комментарии объясняют *почему*; *что* делает код, видно из кода.

Краткая карта проекта:

| Каталог | Что там |
|---|---|
| `src/core` | Настройки, JSON, логи, пути, локализация |
| `src/battery` | Чтение заряда, определение событий, история |
| `src/audio` | Декодирование звуковых файлов и воспроизведение |
| `src/notify` | Превращение события в звук, карточку и toast |
| `src/platform` | Автозапуск, single instance, тема системы, интеграция с оболочкой |
| `src/ui` | Отрисовка: устройство, тема, окно, виджеты, рисование, страницы |
