PowerPeek -- portable
=====================

Run PowerPeek.exe. There is nothing to install and no runtime to add: the executable
needs only Windows 10 version 1809 or newer, 64-bit.

Where your data lives
---------------------
Settings, charge history and the log are kept in

    %LOCALAPPDATA%\PowerPeek

not next to the executable, so the same folder is picked up if you move PowerPeek.exe
elsewhere or replace it with a newer build. Paste that path into the Explorer address bar
to open it.

How to remove it
----------------
1. Right-click the PowerPeek icon in the notification area and quit the application.
2. Delete PowerPeek.exe.
3. Delete %LOCALAPPDATA%\PowerPeek if you no longer want the settings and history.

If you switched on "start with Windows", turn it off in PowerPeek's settings before you
delete the executable -- otherwise Windows keeps trying to start a program that is gone.

PowerPeek -- портативная версия
===============================

Запусти PowerPeek.exe. Устанавливать и доустанавливать нечего: программе нужна только
64-разрядная Windows 10 версии 1809 или новее.

Где хранятся данные
-------------------
Настройки, история заряда и журнал лежат в

    %LOCALAPPDATA%\PowerPeek

а не рядом с исполняемым файлом -- поэтому они подхватятся, если перенести PowerPeek.exe
в другое место или заменить его новой сборкой. Вставь этот путь в адресную строку
проводника, чтобы открыть папку.

Как удалить
-----------
1. Нажми правой кнопкой на значок PowerPeek в области уведомлений и закрой программу.
2. Удали PowerPeek.exe.
3. Удали %LOCALAPPDATA%\PowerPeek, если настройки и история больше не нужны.

Если был включён автозапуск, выключи его в настройках PowerPeek до удаления файла --
иначе Windows будет пытаться запускать программу, которой уже нет.
